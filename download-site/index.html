Getting Started

Download the Windows installer and run the application. You can immediately start by entering a question into the input field. The AI will analyze your query and generate tailored segments for the wheel.

AI Power & Customization

WayaWheel uses cutting-edge LLMs (Grok, Gemini) to generate choices based on your specific question. You can customize your API keys in the settings to use your preferred model for different "personalities" of the wheel.

The Doom System

Every result is assigned a "Doom Level" from 0-100%. Higher doom results trigger more intense AI reactions and, if enabled, the Face-Scream detector for a perfect viral clip.

Extreme Chaos Mode

Activating Chaos Mode increases spin speed by 10x and enables rapid color cycling. The AI switches to "Doom-Heavy" generation, producing progressively more absurd and regret-filled results.

Streamer Setup (OBS)

To use this in a stream:
1. Open OBS
2. Add a "Window Capture" source
3. Select WayaWheel
4. Use a "Color Key" or "Chroma Key" filter if you wish to remove the background for a transparent overlay.

Global Leaderboard

Your results are synced to a global database via Supabase, allowing you to see how your "Regret" compares to users worldwide on the real-time Doom Map.
